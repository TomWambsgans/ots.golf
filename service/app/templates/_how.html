{# Competition-specific oracle, cost and security rules. #}

How do we count hash compressions?

All parties share one random oracle: every distinct bit string gets an independent uniform 256-bit answer. Hashing is the only cryptographic primitive.

A hash call costs one compression per started 512-bit block of its input. Everything else is free.{% if riscv_upper_track %} The RISC-V track additionally counts instructions.{% endif %}

A per-key public parameter, useful for multi-user security, costs nothing: as Justin Drake observed, a block-based hash can pad the parameter to a full block, absorb it once and cache the internal state, so every later call starts from that state for free.

What does 127-bit security mean here?

The attacker sees the public key, queries the oracle at will, receives one signature on a message of its choice, and then outputs a forgery. If the whole experiment (key generation, signing, the attacker's queries and the final verification) never makes more than B compressions, the attacker must win with probability below B / 2127.

Winning means strong unforgeability: the forgery is any accepted message-signature pair other than the one the signer produced. If signing failed, any accepted pair wins.
