{# Shared model, independent of scores and of the lower framework chosen. #}

One oracle, one cost

All parties share one random oracle, the only cryptographic primitive. Each new input bit string gets an independent, uniform 256-bit answer; repeated inputs get the same answer. There are no built-in labels or domain separation.

A query costs one compression per started 512-bit input block, with a minimum of one, even for a repeated query. Any distinguishing bits count as input. Deterministic computation and randomness are free for every party, including the attacker. All cost limits are worst-case, over every execution path.

127-bit security

An attacker sees the public key, may query the oracle, requests one signature on a chosen message, then attempts a forgery. If the whole experiment costs at most B compressions on every run, success must have probability strictly below B / 2127. This includes key generation, signing, the attacker's queries and final verification.

Upper bounds require strong unforgeability: any new accepted message/signature pair counts. For lower bounds, only forgeries on an unsigned message count; if signing fails, any accepted forgery counts.
