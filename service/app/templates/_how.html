{# Competition-specific oracle, cost and security rules. #}

What are the hash and cost rules?

All parties share one random oracle: every distinct bit string gets an independent uniform 256-bit answer. Hashing is the only cryptographic primitive.

A hash call costs one compression per started 512-bit block of its input, tweaks included, and at least one. Every call is charged, even a repeated one. Everything else is free.{% if riscv_upper_track %} The RISC-V track additionally counts instructions.{% endif %}

A per-key public parameter, useful for multi-user security, costs nothing: as Justin Drake observed, a block-based hash can pad the parameter to a full block, absorb it once and cache the internal state, so every later call starts from that state for free.

What does 127-bit security mean here?

The attacker sees the public key, may query the oracle, requests one chosen-message signature, then attempts a forgery. For every budget B covering the whole experiment on every run, success must be strictly below B / 2127. Include key generation, signing, the attacker's queries and final verification.

Every track uses strong unforgeability: any accepted pair different from the signed pair counts, and if signing fails, any accepted pair counts.
